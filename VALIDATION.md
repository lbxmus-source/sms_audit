# Фактические проверки перед передачей

- Установлены зависимости npm, сохранён `package-lock.json`.
- `expo prebuild --platform android --no-install`: успешно создан Android-проект.
- Expo autolinking обнаружил модуль `sms-audit` и класс `expo.modules.smsaudit.SmsAuditModule`.
- `expo export --platform android`: JavaScript успешно собран в Android bundle (575 модулей).
- Проверка совместимости зависимостей в режиме без сети: «Dependencies are up to date». Проверка через сервер Expo не завершилась из-за тайм-аута прокси; это не является полной проверкой онлайн-каталога.
- Все Kotlin-классы анализа, интерфейса, базы результатов и чтения SMS компилировались в отдельной Android-оболочке с Java 17, Gradle 8.9, SDK 35, Kotlin 1.9.25. `testDebugUnitTest assembleDebug`: BUILD SUCCESSFUL. Эти классы побайтно совпадают с версиями в Expo-модуле.
- 110 тестов, 11 наборов, 0 ошибок/падений. Включены тесты правил, кодов, сохранности значений, остановки по отмене, сохранения прогресса, повторной обработки ошибки, валидного JSON-отчёта, исключения сообщений, обработки прерванного сканирования и отката ошибочного импорта.
- Тесты базы результатов выполнены с Robolectric для Android API 28; обнаруженная несовместимость AutoCloseable исправлена.

## Что не проверено

Полный APK именно Expo-оболочки в облаке EAS не собирался. Expo bridge обнаружен автолинковкой; самостоятельная Android-сборка проверяет ядро, но не весь Expo/React Native runtime. Запуск на физическом телефоне, получение READ_SMS от его установщика, скачивание моделей на телефоне и качество реальных переводов ML Kit здесь не проверены. В тестах правил используется управляемая функция перевода вместо настоящей модели.

Проверки не дают гарантии, что все будущие SMS будут переведены правильно. В отчёте явно указано, что проверка смысла ещё не проведена.
