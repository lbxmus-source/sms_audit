# Проверка SMS — отдельное приложение для Android

Версия 1.0.0. Название на телефоне: «Проверка SMS». Идентификатор: `com.berelson.smsaudit.expo`.
Это отдельный анализатор. Основной SMS-переводчик не заменяется.

## Как получить отчёт

1. Установить APK анализатора.
2. Открыть его и нажать «1. Загрузить модели перевода». Выбрать Wi-Fi либо разрешить другую сеть. Первоначально нужен интернет; тексты SMS при переводе не отправляются на сервер перевода.
3. Нажать «2. Прочитать все SMS» и разрешить чтение SMS.
4. Нажать «3. Перевести / продолжить». После загрузки моделей перевод работает без интернета. Можно включить авиарежим.
5. Дождаться завершения. На время проверки приложение удерживает экран включённым. При сворачивании или повороте — пауза; результаты каждого обработанного сообщения уже записаны. Вернуться и нажать «Перевести / продолжить».
6. Просмотреть результаты при необходимости. Они показаны страницами по 50 SMS. В карточке можно исключить сообщение из отчёта. Для возврата исключённых сообщений нужно очистить данные проверки и повторно прочитать SMS.
7. Нажать «4. Сохранить отчёт» или «Поделиться отчётом». Прикрепить полученный `.json` в чат.
8. После анализа отчёта передать актуальный архив исходников основного переводчика. По нему можно подготовить совместимые исправления и правила.

Нажатие «Прочитать все SMS» не имеет искусственного лимита количества сообщений. Обрабатываются записи, доступные Android через системную базу SMS, в том числе входящие и исходящие. Сообщения с буквами иврита попадают в проверку; сообщения без иврита считаются отдельно и пропускаются. RCS, WhatsApp, MMS, удалённые SMS и сообщения другого профиля Android этим способом не читаются.

## Что проверяется

Для каждой SMS сохраняются:
- исходный текст;
- обычный перевод локальной модели Google ML Kit;
- перевод с локальными правилами v4;
- текст после подготовки правилами, защищённые фрагменты и определённая тема;
- признаки потери/изменения чисел, кодов, ссылок, появления служебных маркеров, оставшегося иврита;
- причина отказа или тайм-аут, если перевести не удалось;
- явная пометка `semantic_review: NOT_PERFORMED`.

Все сообщения остаются в отчёте, даже если автоматические проверки не нашли проблем. Отсутствие замечаний **не означает правильность смысла**. Адреса и имена могут обоснованно оставаться на иврите. Неудачные попытки можно повторить отдельной кнопкой.

Обычный перевод ML Kit в отчёте — сравнительный результат. Он не выдаётся за перевод, показанный основным приложением. Анализатор не имеет доступа к его внутренней базе, личному списку «Не переводить», истории слов и установленным вручную темам бесед. За основу встроенных правил взяты сохранённые исходники `sms-master (4).zip` и пакет `sms-translation-rules-v4.zip`. Домены определяются автоматически, наблюдённая история слов пуста. Поэтому точное совпадение с актуальной основной программой не гарантируется.

## Данные и разрешения

Разрешение чтения SMS используется только для чтения. Анализатор не отправляет SMS, не удаляет их и не отмечает прочитанными. Не запрашивает роль основного SMS-приложения. Автоматической передачи в ChatGPT нет: файл передаёт пользователь.

Отчёт содержит полные тексты SMS — включая коды, телефоны и адреса внутри текста. Переключатель отправителей убирает только отдельное поле отправителя, а не персональные данные из текста. Поле `sender_group` — стабильный SHA-256 от отправителя для группировки, а не гарантия анонимности. Резервное копирование данных анализатора в системный бэкап отключено.

«Удалить данные проверки» удаляет внутренние копии и временные отчёты анализатора. Оригинальные SMS и ранее сохранённые во внешние папки файлы остаются.

Если Android или установщик блокирует READ_SMS, анализатор показывает объяснение. Это разрешение может зависеть от способа установки. Как запасной вариант предусмотрены импорт JSON и вставка отдельной SMS. Самостоятельно обходить запрет Android программа не пытается.

## Импорт JSON

Простой массив объектов, UTF-8:

```json
[
  {"original":"קוד האימות שלך הוא 1234","sender":"Example","date":1789920000000,"type":1},
  {"original":"תודה רבה","sender":"Example","date":1789920001000,"type":1}
]
```

Вместо `original` допустимо `body`, вместо `sender` — `address`. `date` — время Unix в миллисекундах; необязательно. `type` — тип SMS в Android; по умолчанию 1. Это формат импорта исходных сообщений, а не формат готового отчёта. Повторный импорт точно такого же массива не повторяет уже готовые переводы. Разные файлы с повторяющимися SMS могут создать дубликаты; для проверки телефона лучше использовать чтение SMS.

## Сборка

Используйте Expo EAS Build по инструкции в `README.md`. Native-модуль находится в `modules/sms-audit/android`.

## Источники и границы выводов

- https://developers.google.com/ml-kit/language/translation — перевод выполняется локально; для пар языков без английского используется английский как промежуточный, что влияет на качество. Google рекомендует оценивать качество на конкретной задаче.
- https://developers.google.com/ml-kit/language/translation/android — загрузка моделей и API перевода на Android.
- https://developer.android.com/training/data-storage/shared/documents-files — сохранение файла через системный выбор места.

Документация подтверждает техническую возможность офлайн-перевода и ограничения модели. Она не доказывает правильность наших правил или будущих переводов. Проверку поведения проекта описывает `VALIDATION.md`; окончательная проверка смысла проводится человеком по отчёту.
