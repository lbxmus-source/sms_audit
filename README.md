# Проверка SMS — проект для Expo EAS Build

Готовый исходный проект отдельного Android-приложения. Оно читает все доступные SMS, отбирает тексты с ивритом, переводит их локально на русский, отмечает возможные ошибки и создаёт JSON-отчёт для загрузки в чат.

**Нужен Expo EAS Build. В Expo Go и Snack чтение SMS и ML Kit не работают: в проект включён собственный Android-модуль.**

## Собрать APK

Нужны компьютер с Node.js 22 LTS или новее и учётная запись Expo.

1. Распакуйте этот архив в отдельную папку.
2. Откройте терминал в этой папке, где находятся `package.json` и `eas.json`.
3. Выполните по порядку:

```sh
npm ci
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --platform android --profile preview
```

При `init` выберите создание нового проекта в своём аккаунте. EAS запишет настоящий `projectId` в конфигурацию. В архиве специально нет выдуманного идентификатора или чужого аккаунта.

Если CLI предложит создать Android keystore, выберите создание нового ключа: это новое отдельное приложение. После сборки откройте ссылку Expo и скачайте APK на телефон.

`preview` в `eas.json` настроен на APK, пригодный для установки на телефон. Это самостоятельная сборка: работающий Metro/компьютер для запуска приложения не нужен.

Можно хранить проект в отдельном GitHub-репозитории и подключить этот репозиторий к своему проекту Expo. Содержимое архива — корень проекта. Папку `modules/sms-audit/android` обязательно загрузить целиком: именно в ней чтение SMS, перевод и отчёты. Корневую папку `android` EAS создаёт сам на этапе prebuild.

Это не один файл `App.js`, который можно вставить в Snack. Expo собирает код проекта, но не создаёт программу из текстового задания.

## После установки

1. Откройте приложение → «Открыть проверку».
2. Нажмите «Загрузить модели перевода». Интернет нужен для первоначального скачивания моделей.
3. Нажмите «Прочитать все SMS» и разрешите доступ.
4. Нажмите «Перевести / продолжить». После загрузки моделей перевод работает без интернета.
5. Дождитесь завершения. Если выйти из приложения, обработка приостанавливается. Уже готовые результаты сохраняются; нажмите «Перевести / продолжить» после возвращения.
6. Нажмите «Сохранить отчёт» или «Поделиться отчётом» и загрузите JSON в чат.
7. После разбора отчёта предоставьте актуальные исходники основного SMS-переводчика для внесения совместимых правил и исправлений.

В отчёте сохраняются **все** обработанные SMS с ивритом, а не только отмеченные программой. Сообщения без иврита учитываются в счётчике пропущенных. Лимита в 50 SMS нет: 50 — только размер страницы просмотра.

## Что означает «проверить перевод»

Программа проверяет сохранность технических значений, служебный мусор, оставшийся иврит и отсутствие русского текста. Она сохраняет оба результата: обычный ML Kit и перевод с локальными правилами v4.

**Программа не может надёжно оценить смысл всех переводов.** Отсутствие замечаний не означает, что смысл правильный. Это проверяется при разборе отчёта. Новые универсальные правила появятся по результатам такого разбора, а не автоматически по сомнительному переводу модели.

## Ограничения доступа

Читаются обычные SMS из системной базы Android, доступные текущему профилю. RCS, WhatsApp и MMS сюда не входят. Анализатор не меняет оригиналы и не запрашивает роль основного SMS-приложения. На некоторых версиях Android/при некоторых установщиках READ_SMS ограничено; приложение покажет сообщение. Предусмотрены импорт исходных SMS из JSON и ручная вставка как запасные варианты.

Отчёт содержит полный текст SMS, включая коды и адреса. Перед выгрузкой можно просмотреть и исключить отдельные сообщения. Переключатель отправителей управляет только отдельным полем отправителя; он не обезличивает сам текст. Файл не отправляется в чат автоматически.

## Структура

- `App.js`: стартовый экран Expo.
- `app.json`: настройки Android и разрешения.
- `eas.json`: облачная сборка APK.
- `modules/sms-audit`: локальный Expo-модуль.
- `modules/sms-audit/android/src/main/java/com/berelson/smsaudit`: чтение SMS, перевод, база результатов, интерфейс и выгрузка.
- `modules/sms-audit/android/src/main/java/com/berelson/smstranslator/translation`: локальные правила v4 и защита значений.
- `modules/sms-audit/android/src/test`: проверки правил и отчётов.
- `FUNCTIONS_RU.md`: описание формата импорта и особенностей анализатора; раздел о CodeMagic относится к автономной Android-версии, для этого архива используйте команды EAS выше.
- `VALIDATION.md`: что реально проверено перед передачей.
